# Demo checklist (do the full run the day before)

- [ ] Laptop charged, charger packed; setup + training done **on this laptop**; `models/waste_model.pt` exists
- [ ] Open `models/classification_report.txt` and `confusion_matrix.png`; know which classes are weak
- [ ] Run `run_app.bat` offline (Wi-Fi off) – confirm it still works
- [ ] Browser: Edge/Chrome; camera permission allowed; volume up; Arabic voice speaks when pressing 🔊
- [ ] Test every real object: sheet, cardboard, book, notebook, water bottle, juice bottle, laban container, chips bag, large + small paper cup, can
- [ ] Wrong/«غير متأكد» results: retake with plain background and light from the front; add photos in the "علّم النموذج" tab and retrain if one item keeps failing
- [ ] Confirm bins in `classes.json` with the school supervisor
- [ ] Explain on stage: it assists sorting, may be wrong, doesn't know the material, and local rules decide
- [ ] Backup: ZIP copy on a USB stick + a few saved photos ready for the upload option
